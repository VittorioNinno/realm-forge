# RealmForge

[🇬🇧 English]  
A modular, multi-language web platform for managing TTRPG campaigns, sessions, and rules (inspired by modern D&D mechanics).

[🇮🇹 Italiano]  
Piattaforma web modulare e multilingua per la gestione di campagne, sessioni e regole TTRPG (ispirata alle meccaniche moderne di D&D).

---

## 🛠️ Tech Stack / Tecnologie Principali
- **Backend:** ASP.NET Core (C#)
- **Frontend:** Blazor WebAssembly / Custom UI
- **Database:** PostgreSQL (managed via Entity Framework Core / gestito tramite Entity Framework Core)

## 🌍 Project Goals / Obiettivi del Progetto
- **[EN]** Native multi-language support (starting with English and Italian, built for future localizations).  
- **[IT]** Supporto nativo multilingua (inizialmente Inglese e Italiano, con un'architettura aperta a future localizzazioni).  

- **[EN]** Flexible management of character sheets, class rules, species, and compendiums.  
- **[IT]** Gestione flessibile delle schede personaggio, regole di classe, specie e compendi.  

- **[EN]** Clear separation between SRD content (public domain) and Homebrew/private content.  
- **[IT]** Netta separazione tra i contenuti SRD (dominio pubblico) e i contenuti Homebrew/privati.
